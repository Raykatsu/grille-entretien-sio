# Grille d'entretien SIO

Outils du projet **SAé Coaching SIO** pour accompagner les étudiants de BTS SIO option SISR dans leur recherche de stage, d'alternance et d'emploi.

## Grille d'observation en ligne

La page `index.html` est une grille d'observation pour les simulations d'entretien en trio (candidat, recruteur, observateur). Elle fonctionne sur ordinateur et sur téléphone :

- une note de 1 à 4 par critère et un champ « faits observés » ;
- le total calculé automatiquement, par partie et sur 72 ;
- les points forts, les axes de progrès et le plan de progrès du candidat ;
- un **compte rendu** (complet ou synthèse) à envoyer par mail, WhatsApp ou SMS, à copier, à télécharger en .txt ou à imprimer en PDF.

Les notes restent dans le navigateur de l'appareil utilisé : aucune donnée n'est envoyée sur un serveur.

## Fiches imprimables (dossier `fiches/`)

| Fichier | Contenu |
|---|---|
| `Fiches_preparer_entretien_SIO.pdf` | 6 fiches pour préparer un entretien d'embauche |
| `Fiches_CV_video_SIO.pdf` | 6 fiches pour réaliser un CV vidéo |
| `Grille_simulation_entretien_SIO.pdf` | Kit papier de simulation d'entretien en trio |

## Contribuer

Pour modifier la grille, éditer `index.html` (une seule page, sans dépendance) puis pousser sur `main` : le site se met à jour automatiquement.
